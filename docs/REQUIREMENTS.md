# A 股量化研究台需求分析

## 1. 产品定位

面向有 Python 基础或愿意使用本地工具的个人 A 股投资者，提供一条可复现的研究闭环：

> 获取行情 -> 形成信号 -> 按 A 股规则回测 -> 检查风险 -> 记录结论

第一阶段是研究和模拟工具，不连接券商、不自动下单，也不承诺任何收益。

## 2. 用户目标

1. 用统一界面查看关注标的与市场状态。
2. 不写代码也能配置并运行一个基准策略。
3. 看到收益之外的回撤、波动、夏普、交易次数和费用侵蚀。
4. 回测结果能够解释：每笔交易何时、为何、以什么成本成交。
5. 后续可接入 AkShare、Tushare 或付费数据，而无需改写策略和回测核心。

## 3. 第一版功能范围

### 行情层

- 内置确定性演示行情，首次启动无需账号和 Token。
- 标准日线字段：交易日、开高低收、成交量、停牌、涨跌停价格。
- `MarketDataProvider` 接口隔离数据源，后续接入真实行情与 Parquet/DuckDB 缓存。

### 策略层

- 双均线趋势策略作为透明、易解释的基准。
- 信号只使用当日及此前收盘数据，并在下一交易日开盘尝试成交，避免未来函数。
- 策略参数通过类型化 API 输入，服务端统一校验。

### 回测层

- 仅做多，不融资融券。
- 100 股一手；资金不足时自动向下取整。
- T+1：当日买入股份当日不可卖出。
- 买卖佣金支持费率与最低 5 元；卖出收印花税；支持滑点。
- 停牌不成交；涨停不可买入；跌停不可卖出，订单顺延到下一交易日。
- 输出净值曲线、回撤、交易流水、总收益、年化收益、波动率、夏普、最大回撤、胜率和总费用。

### 研究台

- 市场概览、关注列表、策略参数、回测操作与结果展示。
- 桌面端偏高信息密度，移动端保持完整流程和可读性。
- 明示当前数据源和“仅供研究”属性。

## 4. 第一版不做

- 不接券商实盘，不保存交易密码或 Token。
- 不做分钟级/高频回测，不模拟盘口和成交队列。
- 不先做机器学习选股、因子挖掘或复杂组合优化。
- 不用演示行情验证策略有效性，演示数据只验证系统流程。

## 5. 关键风险与验收标准

| 风险 | 第一版应对 | 验收 |
|---|---|---|
| 未来函数 | 收盘产生日后信号，下一交易日开盘成交 | 单元测试验证首笔成交日 |
| 交易成本低估 | 佣金最低收费、印花税、滑点分开计算 | 成本测试覆盖买卖两侧 |
| A 股成交约束缺失 | 手数、T+1、涨跌停、停牌建模 | 规则测试可复现 |
| 演示结果被误解 | 页面和文档持续标注演示数据/研究用途 | 首屏可见 |
| 数据源锁定 | Provider 协议与领域模型隔离 | 演示源可替换 |

## 6. 后续迭代

1. **真实数据**：AkShare/Tushare 适配器、交易日历、前复权与原始价双轨、增量缓存。
2. **研究能力**：截面因子、股票池、基准对比、滚动回测、参数稳定性和样本外验证。
3. **组合风控**：行业暴露、单票上限、波动率目标、再平衡和风险预算。
4. **模拟交易**：交易计划、订单审核、持仓对账和告警；成熟后再评估券商接口。
